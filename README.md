# Retro Pixelizer Pro video

导入你的视频，调整参数，把它变为复古的像素艺术风格！
灵感来源于chixi4

## 主要功能

* **多种抖动算法**：内置 Atkinson, Floyd-Steinberg, Bayer (4x4, 8x8) 及随机噪点等经典算法。
* **丰富调色板**：预设 Dreamscape8, Red Noir, GameBoy 等几十种精选复古配色。
* **精细控制**：
    * 支持自定义像素化尺寸（32px - 640px）。
    * **影调调色台**：通过拖拽光标，实时调整画面的对比度与明暗。
* **纯本地运行**：单 HTML 文件应用，所有图片处理均在浏览器本地完成，保护隐私。
* **全平台支持**：适配手机与电脑端，支持深色/浅色模式切换。

**离线使用**
下载本仓库的 `video.html` 文件，直接双击使用浏览器打开即可，无需安装任何环境。

## 提示

* **静默捕获**：用 Web Audio 把音频单独抽出来接进录音流、但不接扬声器——这样导出时不会外放原声，音画依然同步（因为是实时录制）。
* **回退**：如果浏览器不支持 Web Audio，则回退使用音频流捕获（此时导出会外放原声）。
导出会从头实时播放一遍并录制，完成后自动下载带原声的视频。若源视频本身没有音轨，会提示「源视频无音频轨」。

* **说明**：受限于纯浏览器方案，导出是实时渲染，即时长 ≈ 原视频时长。
